# Aurora OS 5.1.0.04

- Refined Start menu hierarchy with an accent header, clearer pinned-app section, and improved spacing while retaining searchable app results.
- Expanded notification history from 6 to 12 entries using fixed-capacity static storage.
- Added a live notification count and free-memory readout to the notification panel.
- Changed notification title/body storage from borrowed pointers to bounded in-ring copies, preventing transient caller buffers from becoming dangling references.
- Kept individual dismissal and Clear all behavior; notification storage does not allocate from the kernel heap.
- Preserved the AuroraNotes buffer-terminator fix from 5.1.0.03.
- Browser network transport remains unavailable; no full networking or user-space notification daemon is claimed.
