# Aurora OS M5.0.3 — Window animations and notifications

- Window opening uses a short 180 ms upward slide; closing uses a short downward slide before the window is removed.
- Animation transitions trigger redraws until completion.
- Added a notification bell icon immediately to the left of the clock/date area on the bottom taskbar.
- Clicking the bell toggles a notification flyout with a caught-up state and system status placeholder.
- Clicking outside the notification flyout dismisses it.
- Existing desktop, wallpaper, and resolution controls remain in place.

## Validation
- Kernel compiled and linked successfully with GCC/LD.
- ISO generated using the repository's ISO builder; El Torito BIOS/UEFI entries reported.
- Runtime graphical behavior has not been tested in QEMU/VMware in this environment.
