# Aurora OS 5.1.0.16 — API and browser input hardening

- Bumped the platform capability API to v2 and added `aurora_platform_get_info_sized()` to validate caller buffer size before writing.
- Kept the original typed API as a compatibility wrapper.
- Tightened browser address validation: explicit `http://` or `https://` is required; malformed/empty authorities, whitespace/control bytes, backslashes, userinfo, and empty host labels are rejected.
- Updated UI, boot menu, kernel log, README, and ISO volume metadata.
- This source still does not implement packet I/O, TCP/IP, DNS, TLS certificate validation, or a modern browser engine. Accepted addresses are not fetched.
