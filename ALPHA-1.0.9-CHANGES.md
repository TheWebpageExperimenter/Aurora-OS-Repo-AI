# Aurora OS Alpha 1.0.9

- Redesigned lock-screen typography with a large, extra-bold time display.
- Reduced date text size and included weekday + month/day in the compact line above the clock.
- Retained the existing lock-screen layout, profile, sign-in control, and background rendering.
- Updated kernel startup, Limine, and ISO metadata.

Validation: compilation and ISO packaging are checked for this build. Runtime visual testing has not been performed. The bold weight is simulated by repeated bitmap-font passes because the current renderer uses fixed-size bitmap fonts.
