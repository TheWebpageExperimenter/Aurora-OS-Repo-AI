# Aurora OS

Bootable x86-64 kernel (freestanding C) loaded by the Limine bootloader.

## Status: M4 desktop experience preview (based on the M3 kernel)
- **Desktop shell** (runs inside the kernel until user space exists): aurora wallpaper,
  desktop icons (double-click to open), live clock from the CMOS RTC
- **Boot splash and sign-in**: Aurora startup screen followed by a classic early-2010s,
  blue-glass login panel; press Enter or click Sign in to open the desktop (demo session, no password validation)
- **Taskbar** docked **bottom, left or right**; large icons (24 / 32 / 40 px, default 32) and a larger 24 px clock in the taller taskbar;
  centered Start/search/few pinned app icons, running-app indicators, minimise/restore by clicking,
  "show desktop" strip, and a translucent cyan Frutiger-Aero glass finish
- **Start menu**: pinned app grid, live search (type, Enter launches best match),
  user bar, power button (ACPI shutdown on QEMU/Bochs/VirtualBox)
- **Window manager**: drag by title bar, minimise, close, focus/raise, drop shadows
- **Apps**: AuroraFM (demo listing - no filesystem yet), AuroraNotes (typing works),
  AuroraMonitor (real memory, uptime and UI-FPS graph), AuroraSettings (System,
  Personalization, About)
- **Personalization** (live): taskbar position, icon size, accent colour, which apps are
  pinned to the taskbar / Start menu
- **Graphics**: double-buffered 32-bit renderer, anti-aliased rounded rects / circles /
  lines, alpha blending, Spleen bitmap fonts (6x12, 8x16, 12x24), vector icon set - integer math only
- **Input**: polled PS/2 keyboard (scancode set 1) and mouse; the Super/Windows key toggles Start
- **Timing**: TSC calibrated against the PIT, RTC clock (shown as UTC)

Milestone 2 features remain: GDT/TSS + IST stacks, IDT + panic screen, physical memory
manager (now with `pmm_alloc_contiguous`), `kprintf` / `ksnprintf`.

## Build and run
    sudo apt install gcc make xorriso qemu-system-x86 git python3
    make                # aurora.iso
    make run            # QEMU; click inside the window to capture the mouse (Ctrl+Alt+G releases)
    make FAULT=pf       # deliberate crash to show the panic screen (div | pf | ud | df)
    make clean

## VMware
"Other 64-bit" VM, BIOS firmware, 4 GB RAM, attach aurora.iso, 3D acceleration off.

## Layout
    kernel/main.c       Limine requests, boot sequence, self-tests, starts the GUI
    kernel/gui.c        desktop, taskbar, Start menu, window manager, apps
    kernel/gfx.c        renderer: back buffer, shapes, text, wallpaper, cursor
    kernel/icons.c      procedural vector icons
    kernel/input.c      PS/2 keyboard + mouse
    kernel/time.c       TSC calibration, RTC
    kernel/gdt.c idt.c isr.S pmm.c console.c printf.c panic.c string.c serial.c
    kernel/font_spleen.h   generated by tools/bdf2c.py from tools/spleen-*.bdf
    limine/             Limine v8.x binary release (BSD-2-Clause)

## Known limitations
- Input is polled (no IRQs/APIC yet), so the VM spins a host CPU core
- AuroraFM shows demo data; Notes are not saved (no filesystem)
- Monitor has no CPU-load graph (needs the scheduler)
- Clock shows the RTC as-is (UTC under QEMU); no time-zone setting yet
- Tested in QEMU (BIOS boot); UEFI and VMware paths not yet tested
