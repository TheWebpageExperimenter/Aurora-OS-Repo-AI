# Aurora OS Milestone 5.0.1 — Bugfix release

- Boot default reset to 1280×720×32 to avoid requesting a larger framebuffer at startup on virtual adapters that may not map it safely.
- Updated kernel boot console and About panel to identify version 5.0.1.
- Clean rebuild to prevent stale object files from leaking into the release.
- Retained wallpaper preset UI and mode selector. Mode scaling remains a known limitation for the generated placeholder backgrounds.
- Sound support for VMware/VirtualBox is not yet fully implemented; this release does not claim otherwise.

Validation: compile/link and ISO structural checks. No live QEMU/VMware/VirtualBox boot was available, so runtime behavior remains unverified.
