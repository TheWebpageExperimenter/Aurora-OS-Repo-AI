# Aurora OS 5.1.0.15-r2 — networking API hardening

## Security and correctness fixes
- Added `aurora_net_get_info_sized()` to the PCI network-discovery API. It rejects null or undersized caller buffers before copying the information structure, reducing the risk of an ABI-size mismatch causing a caller-buffer overwrite.
- The sized query builds a zero-initialized bounded snapshot and clamps the reported NIC count to the fixed array capacity before copying entries.
- Retained `aurora_net_get_info()` as a compatibility wrapper for callers that allocate the current full structure.
- Bumped the network API version to 2 and updated release/ISO metadata.
- Clean rebuild requested to avoid stale generated dependency files from earlier builds.

## Important scope note
The 5.1.0.15 source baseline contains PCI network-adapter discovery only. It does **not** contain TCP/IP packet processing, a NIC packet driver, or a transport stack. Therefore this release hardens the network discovery API and build consistency; it does not claim to fix a TCP/IP stack vulnerability that is not present in this source tree.

## Verification
Compilation and ISO/archive integrity checks should be completed for this build. Runtime boot and adversarial memory testing require a VM/hardware test environment.
