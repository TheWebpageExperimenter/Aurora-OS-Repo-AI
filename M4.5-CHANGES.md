# Aurora OS M4.5 changes

- Reworked the sign-in panel into a cleaner blue-glass profile screen with Aurora branding, avatar, obvious Sign in button, and explicit demo-session / no-password disclaimer.
- Updated the taskbar to a more Windows 11-like centered rounded island over a shorter 56 px background strip. Default icon size remains 32 px; 24 and 40 px options remain.
- Replaced the GUI's Spleen bitmap renderer with an antialiased atlas generated from the bundled Go Medium TrueType font; source TTF assets and BSD-3-Clause license are included. The font atlas is embedded because there is no VFS yet.
- Added an Aurora Browser app and browser icon, pinned it by default, and added an editable address bar initialized to `https://www.google.com/` plus a Go action.
- Browser reports network/TLS readiness accurately: no requests are sent and no certificate is reported valid. A real browser still requires NIC support, TCP/IP, DNS, TLS, and a trusted CA store.
- Added `tools/mkiso.py` as an ISO packaging fallback for hosts without `xorriso`, retaining BIOS and UEFI El Torito entries.

### Boot compatibility fix
- Corrected the El Torito boot-system identifier to use NUL padding as required by the boot-record format; the previous space-padded identifier could keep BIOS firmware from recognizing the boot catalog.
- Fixed the custom ISO fallback: NUL-pad the El Torito boot-system identifier and avoid applying a hard-disk MBR installer to a non-hybrid CD image.
