# Aurora OS Milestone 5.0.2 — Resolution framebuffer fix

- Fixed the resolution selector rejecting every mode larger than the initial 1280x720 framebuffer.
- Limine now requests a 1920x1080x32 boot framebuffer so the full maximum supported display aperture is available at boot.
- Kernel startup switches the desktop down to 1280x720 after capturing the larger mapped framebuffer capacity.
- Runtime mode switching still validates hardware support, video memory capacity, pitch, and framebuffer mapping before updating renderer metadata.
- This specifically targets the “Mode rejected or mapped framebuffer space is insufficient” message shown when selecting 1366x768, 1600x720, 1823x918, or 1920x1080.

Build verified; a live QEMU/VMware runtime test was not possible in this environment.
