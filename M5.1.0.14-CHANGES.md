# Aurora OS 5.1.0.14 — Kernel hardening and fixes

- Hardened PMM startup against missing/empty boot memory-map responses.
- Added overflow guards before rounding physical memory range bases up to page boundaries.
- Preserved existing checks for invalid ranges, bitmap sizing, non-usable frees, and double frees.
- Updated kernel, GUI, Limine menu and ISO metadata to version 5.1.0.14.

Validation: source compilation/link and ISO/archive integrity checks are performed for this build. Runtime boot testing depends on QEMU being available.
