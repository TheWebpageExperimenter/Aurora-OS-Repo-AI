# Aurora OS Alpha 1.0.5.2

- Removed Nikitas, Dark Strider, and Windows 11 artwork from the Settings wallpaper choices. The remaining choices are Aurora, Blue Horizon, Neon Bloom, Emerald, Solar Flare, Continuator, and Nikitas (Default).
- Login screen now keeps the active desktop wallpaper as its background, with subtle translucent sign-in accents layered on top.
- Improved the browser UI address bar to accept HTTP/HTTPS URLs, hostnames without a scheme, and search phrases (prepared as Google search URLs). Browser navigation remains a UI/URL-preparation feature only: no network request is sent because the kernel still lacks packet I/O, TCP/IP, DNS, TLS, and HTTP transport.
- Updated Alpha 1.0.5.2 release branding.
