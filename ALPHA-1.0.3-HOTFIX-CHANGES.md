# Aurora OS Alpha 1.0.3 Hotfix

## Fixes
- Fixed accent preset selection so choosing a built-in color disables custom RGB override and visibly applies the selected accent.
- Selecting a preset synchronizes the RGB controls to that preset's channel values.
- Added fixed up/down scroll controls to Settings and clipped the settings content area so long pages can be navigated without drawing over the window chrome.
- Reset the scroll position when switching Settings pages.

## Validation
- Kernel build completed successfully.
- No compiler warning/error messages were found in the build log.
- ISO generated using the repository's ISO builder.
- Runtime GUI behavior has not been tested in a booted VM.
