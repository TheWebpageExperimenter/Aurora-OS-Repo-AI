# Aurora OS 5.1.1.1111111111111111111111111111111.11176

## Changes
- Added a maximize/restore control between minimize and close in window chrome.
- Implemented maximize/restore geometry bookkeeping for desktop windows.
- Refreshed the taskbar with a translucent rounded glass surface and subtle highlight edge inspired by Frutiger Aero.
- Retained the existing kernel security monitor API and periodic integrity/invariant checks.
- Updated GUI, boot-menu, kernel, and release metadata.

## Scope and validation
The security monitor is an audit/integrity facility, not a complete security boundary or permission system. The desktop remains software-framebuffer rendered; no hardware-accelerated glass or compositor was added. Dragging existing title bars remains supported. Long-press dragging taskbar icons to reorder them is not implemented in this release.
