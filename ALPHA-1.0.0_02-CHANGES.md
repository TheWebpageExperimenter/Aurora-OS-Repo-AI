# Aurora OS Alpha 1.0.0_02

- Updated kernel build label to `102620261126`.
- Redesigned Aurora Notes with a compact File/View toolbar and flyouts.
- File flyout provides New note and Clear note actions.
- View flyout toggles the status bar.
- Added distinct procedural vector icons for Messages, Clock, and Maps; reused consistently in taskbar pins, Start menu, and window title bars.
- Existing apps remain in Start menu/taskbar pin configuration.

Limitations: note contents remain volatile because persistent filesystem storage is not implemented. Messages and Maps are local demo interfaces; no messaging service or live map/network stack is provided. Runtime boot testing has not been performed.
