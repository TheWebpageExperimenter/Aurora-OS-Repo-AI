# Aurora OS 5.1.0.03

- Refined Start menu heading and pinned-app layout.
- Replaced the placeholder notifications panel with a bounded six-entry notification center, clear-all action, individual dismiss, and quick system status.
- Added browser URI result notifications for accepted/rejected input.
- Fixed AuroraNotes backspace/append bookkeeping to keep its buffer terminator consistent.
- Kept notification storage statically allocated to avoid kernel-heap leaks and unbounded allocations.
- No full browser network transport or production notification daemon is implied; this remains an in-kernel shell prototype.
