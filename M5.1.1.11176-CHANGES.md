## Implemented
- Added versioned Taskbar Style Kernel API (`taskbar_api.h/.c`, API v1) to query/set taskbar colour enablement and one of five colour schemes.
- Settings > Personalization now contains an enable/disable taskbar-colour toggle and Aero, Ocean, Graphite, Amber, and Violet scheme choices.
- Taskbar renders the selected colour scheme when enabled and a neutral dark style when disabled.
- Browser shell no longer pretends to load websites. It clearly indicates that Firefox is not bundled and cannot execute in the current kernel-only build.

## Important limitation
This build does **not** contain Mozilla Firefox, a user-space process/exec environment, or a complete browser runtime. It therefore cannot honestly provide real Firefox or claim Google, Bing, or arbitrary websites work. Running Firefox requires a user-space runtime, process and memory isolation, filesystem and network integration, graphics/window embedding, and a compatible Firefox build. The current browser screen is an explicit integration notice, not a functional web browser.
