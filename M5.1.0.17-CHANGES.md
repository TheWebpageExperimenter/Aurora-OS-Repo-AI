- Bumped the platform capability API to v3 and added a structure-size field.
- Made the platform information query explicitly report the currently implemented software-framebuffer renderer and PCI discovery only; unsupported networking, accelerated graphics, userspace ABI, and browser features remain unadvertised.
- Preserved the size-checked query contract: null or undersized output buffers fail without writing.
- Updated GUI, kernel boot menu, README and ISO volume metadata to 5.1.1.7111611116226262627484848484.100.

## Compatibility notes

The GUI still renders through a software framebuffer supplied by Limine. This path is suitable as a baseline for QEMU, VMware, and VirtualBox when their virtual graphics adapter exposes a compatible framebuffer, but this release does not add VMware SVGA, VirtualBox VMSVGA, or virtio-gpu accelerated drivers. Runtime/app execution remains limited because a userspace ABI and application loader are not implemented. Modern websites are not supported because TCP/IP, DNS, TLS certificate validation, and a browser engine are absent.
