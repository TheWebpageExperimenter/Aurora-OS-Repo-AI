# Aurora OS 5.0.4-b2 — Kernel hotfix

## Kernel changes
- Hardened `pmm_free()` so a physical page must belong to a bootloader-reported USABLE memory range before it can be released. This prevents accidental release of reserved/firmware/kernel pages.
- Preserved checks for invalid alignment, out-of-range addresses, and double frees.
- Updated the startup banner and PMM status message to identify the b2 kernel build.
- Rebuilt the freestanding x86-64 kernel and bootable ISO from source.

## Validation
- `make clean && make -j2`: passed without compiler/linker warnings.
- ISO generator reported a 4,122,624-byte image and BIOS/UEFI El Torito entries.
- QEMU and physical laptop boot tests were not run in this environment.
- This is a kernel memory-manager hardening hotfix, not a claim of a complete installer fix or full hardware compatibility.
