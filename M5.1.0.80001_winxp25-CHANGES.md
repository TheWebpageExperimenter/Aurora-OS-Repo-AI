# Aurora OS 5.1.0.80001_winxp25

- Added Aurora Network API v1 with a fixed versioned NIC information structure.
- Added PCI configuration-space discovery for Intel E1000, VirtIO-net, VMware vmxnet3, Realtek RTL8139, and AMD PCnet adapters.
- Integrated discovery into boot diagnostics and Aurora Browser status.
- Updated boot/version branding, Limine menu and ISO metadata.

## Explicit limitations
This version detects selected PCI network adapters; it does not initialize their DMA/rings or send packets. DHCP, Ethernet/ARP, IPv4, TCP, DNS, HTTP, TLS and certificate validation remain unimplemented. Browser Go/Reload still performs no web request. Do not treat this milestone as internet-connected or HTTPS-secure.

Build status: compilation succeeded without compiler warnings/errors; bootable ISO 9660 image generated and verified. Virtual machine boot tests pending.
