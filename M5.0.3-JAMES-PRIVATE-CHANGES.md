# Aurora OS 5.0.3 (james) — Private Kernel Build

## Kernel hardening changes
- Updated the boot console version string to identify the private `5.0.3 (james)` build.
- Hardened PMM memory-map processing against `base + length` overflow and clipped ranges to the bitmap-managed physical page span.
- Page-aligns the physical page bitmap location and verifies that the bitmap fits fully within a usable memory-map entry.
- Validates bitmap sizing and page counts before allocation.
- Tightened contiguous physical allocation: rejects impossible requests early, handles bitmap scan skips safely, updates the allocation hint, and avoids scanning beyond the managed page count.
- Added overflow guards to graphics back-buffer allocation calculations before allocating contiguous pages.
- Preserves existing desktop features: window transitions, notification flyout, wallpaper presets, and resolution controls.

## Build and validation
- Rebuilt the kernel from source and generated a bootable ISO using the repository build pipeline.
- Compiler/linker and ISO structural checks are recorded with the release artifacts.
- This is a private development build, not a claim of full VMware/VirtualBox audio or accelerated graphics support. Runtime testing requires booting it in the target hypervisors.
