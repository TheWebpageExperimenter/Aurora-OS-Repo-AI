# Aurora OS 5.1.0

- Improved boot diagnostics with Limine bootloader metadata where provided.
- Clearer panic message when the bootloader omits required memory-map or HHDM responses.
- Boot menu now waits five seconds before automatically starting Aurora, allowing recovery selection.
- Login screen and version labels updated to 5.1.0; explicitly identifies the current session as a demo and does not imply password security.
- Updated ISO volume and boot-catalog labels.

Validation: source build attempted in the provided environment; booting in a VM is still recommended.
