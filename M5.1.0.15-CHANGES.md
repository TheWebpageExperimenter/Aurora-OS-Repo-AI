# Aurora OS 5.1.0.15 changes

- Added Aurora Platform Capability API v1 with null-safe query semantics and reserved field for forward compatibility.
- Added explicit web-readiness reporting so apps can distinguish discovered hardware from usable network/browser support.
- Boot diagnostics print the platform API version and a capability mask.
- Updated release labels and ISO volume metadata.

## Compatibility status
This release does not make modern websites or web apps work by itself. Network packet drivers, TCP/IP, DNS, TLS 1.3, certificate-chain and hostname validation, trusted CA roots, a userspace ABI, and a modern browser engine remain unimplemented. The browser is still a UI prototype.
