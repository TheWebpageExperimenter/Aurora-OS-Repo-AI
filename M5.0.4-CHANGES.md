# Aurora OS 5.0.4 — Boot Experience Update

- Replaced the text-heavy splash with a short, crisp animated startup scene.
- Removed all visible brand/name and status text from the splash.
- Reduced blur-like translucent shapes; uses sharp color bands, thin rings, orbiting dots, and a slim progress line.
- Set Limine timeout to zero to skip the text boot menu during normal startup.
- Existing desktop/login flow is retained.

Validation: kernel compilation and ISO packaging are performed for this build. A full QEMU/VMware graphical boot test is not available in this environment.
